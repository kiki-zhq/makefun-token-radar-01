How the implied value is worked out model radar-2

One formula scores every protocol — no name is ever special-cased. A token’s value grows with TVL, but with diminishing returns, so the multiple is a power law in TVL; seven-day growth and how long the protocol has run with no token move it up or down; running on more chains adds a little reach.

implied = TVL × clamp(0.60 × (TVL / $1M)−0.15, 0.10, 0.60) × (1 + clamp(7d change, −70%, +200%) × 0.6) × (0.55 + 0.45 × min(age, 4y) / 4y) × (1 + 0.04 × extra chains, max 4)

Age is days from the day DefiLlama began tracking the protocol to the snapshot date; a protocol with no tracking date counts as one year old. A missing seven-day change counts as 0%.
